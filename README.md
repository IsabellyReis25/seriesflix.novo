# 🎬 SeriesFlix + ⚖️ Comparação de design

Projeto da feira técnica: o **SeriesFlix** (site com design caprichado) e o **O Tordo · Jogos Vorazes** (site quase sem CSS), para mostrar a diferença que o CSS faz.

## Como abrir
Abra `index.html` no navegador. Não precisa instalar nada.

## Arquivos
- `index.html` – SeriesFlix
- `styles.css` – todo o design do SeriesFlix (comentado por seções)
- `jogos-vorazes.html` – o site "feio", de propósito
- `img/` – imagens das séries

## Para apresentar
1. Mostre o SeriesFlix (hero, cards, filtros por gênero, modo claro/escuro).
2. Na seção **"Design faz toda a diferença"** (botão ⚖️ Comparar no topo):
   - **Ver site Jogos Vorazes** abre o site sem design.
   - **Desligar o CSS deste site** mostra o próprio SeriesFlix só com HTML. Depois clique em **Ligar o CSS de novo**.
